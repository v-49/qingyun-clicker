# 轻云 内测 v2.0 beta 界面壳子

这是按当前桌面版样式复刻的网页壳子。默认打开「连点模式」，切换到「操作录制」讨论 2.0。

从仓库根目录启动 `python -m http.server 8765 --bind 127.0.0.1` 后，访问 `http://127.0.0.1:8765/prototype/`。也可双击 `index.html`；本地存储行为取决于浏览器。

当前内容：

- 连点：输入方式、分组、动作录入、组合键、间隔/启停/按住、排序、快捷键；每行在间隔右侧固定显示“持续 [50] ms”，默认50，直接独立修改。没有顶部全局时长或自定义开关；0 ms 为立即松开，“按住”不使用点按时长。
- 2.0：底栏直接启动，组标题显示录制状态与时长；暂停、继续、停止；已有步骤的编辑、排序、导入/导出和回放时间线。录制期间切走页面不会暂停。没有录制弹窗、体验区、示例入口或强制倒计时。
- 分组与设置存到浏览器本地；原型 JSON 导入/导出。

本网页未接入 Windows 全局采集。启动表示录制状态，停止不会制造步骤。全屏游戏的真实轨迹、键盘事件和全局快捷键需由桌面引擎实现；当前网页的快捷键仅在页面获得焦点时有效。回放只推进界面时间线，不发送输入。定时关机保留原入口，未执行系统操作。

本地存储使用 `qingyun-prototype-v3`；上一版 `qingyun-prototype-v2` 保留，只迁移连点配置，不迁移网页体验区宏。JSON 仍用独立文件格式，不可直接交给桌面程序执行。

产品判断：[v2-product-analysis.md](../docs/v2-product-analysis.md)。设计依据：[brand-spec.md](brand-spec.md)。

最新的同键短连发、改键与组内编排/录制层级见 [clicker-product-architecture.md](../docs/clicker-product-architecture.md)。桌面 beta.3 已接入绑定与短连发，并提供“绑”编辑框，本网页尚未同步对应的绑定编辑界面。组内录制与序列输出仍待实现。

桌面版已实现按下时长、原生物理绑定、同键短连发、按住连发与组合间隔，本地内测 EXE：`dist/QingyunClicker-v2.0-beta3.exe`。未接入全屏录制。本目录仍为讨论原型，网页数值不控制桌面输入。
