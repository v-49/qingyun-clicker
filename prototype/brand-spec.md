# 轻云 2.0 网页原型设计依据

- 模式：Extension。将现有桌面 UI 复刻为网页，新增操作录制入口；按下时长固定放在动作行间隔右侧，并同步桌面实现。
- 来源：`../DESIGN.md`、`../main.py`、`../docs/images/main-window.png`。基线提交 `6c10525`。
- 图标：`assets/qingyun.png`，从仓库真实 `app.ico` 转出；原版截图：`../docs/images/main-window.png`。
- 背景 `#faf9f6`，控件 `#fdfdfb`，正文 `#292f29`，辅助文字 `#747a70`。
- 分组激活背景 `#e9eee5`，分段控件背景 `#eeede8`，边框 `#e0e2d9`。
- 启动按钮 `#ebeff1` / `#485863` / `#dce3e7`；录制状态使用原代码删除状态的 `#aa352e` / `#f7e9e7`。
- 字体：Microsoft YaHei UI / Microsoft YaHei，14px 主控件；时间和坐标使用 Consolas 等宽字体。
- 间距：4px 基础，主框横向 20px 内边距，动作行纵向 7px、横向 6px；主内容间距 9px。
- 圆角：控件 10px，分段选择 12px；边框 1px，无装饰性卡片阴影。
- 动效：状态/悬停反馈 120ms；模拟回放用时间推进高亮，不加装饰进场。
- 叙事角色：可操作讨论工具；观看距离：笔记本屏幕；温度：安静；容量：一个主窗口完成录制/编辑/回放。
- Design Read：桌面应用扩展原型；visual variance 2，motion 2，density 8，asset dependence 3，brand fidelity 10。
- 保护：原版分组、动作行、底栏排列和配色；1.0 原生配置键及旧 JSON 读取兼容。
- 布局：模式切换并入原来的输入方式一行；保留分组、动作行和底栏位置；删除额外模式行、状态栏、页面外提示和所有演示说明。
- 按下时长：每行间隔右侧固定显示“持续 [11] ms”，沿用时间框样式，宽112px；删除顶部全局时长与自定义开关，不新增工具栏行；每行独立保存数值，“按住”模式下禁用。
- 录制：底栏直接启动，当前组标题显示状态与时长；主窗口失去焦点不自动暂停；不出现录制弹窗或体验区。
- 实现范围记录在 README，界面只保留操作控件和必要状态。当前未接入 Windows 全局捕获，停止不会生成虚假录制结果。
- 新版使用本地存储键 `qingyun-prototype-v3`，旧 `qingyun-prototype-v2` 保留供恢复；文件格式 `qingyun-web-prototype`，不可导入桌面程序。
