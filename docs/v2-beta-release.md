## 监听实现依据

Windows 低级钩子由安装线程的消息循环分派，回调超时可能导致钩子移除，因此监听使用独立线程，回调只更新物理状态和提交事件，执行与等待留在调度线程。[Microsoft LowLevelKeyboardProc](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelkeyboardproc)

键盘和鼠标钩子中的注入标记用于排除软件生成事件，避免同键连发递归。停止键依据真实按下集合识别，不把输出中的 Ctrl/Shift 等当成物理修饰键。[KBDLLHOOKSTRUCT](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-kbdllhookstruct)、[MSLLHOOKSTRUCT](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-msllhookstruct)
