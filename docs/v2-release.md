# V2.1 正式版

2026-10-22，版本 `2.1.0`。窗口显示“轻云连点器 — V2.1”。[下载 Windows 正式版](https://github.com/v-49/qingyun-clicker/releases/tag/v2.1.0)，文件 `QingyunClicker-v2.1.exe`。

- 录制编辑顶部加入“加速”1×、2×、3×、5×，原底栏即时显示原时长→预计回放时长，主列表时长同步计算。
- 只压缩未按住键鼠时的连续屏幕移动；点击、长按、拖拽、组合重叠区间、空白停顿及相对移动保持原速。循环间隔独立保留。
- 预估、试放、单次/循环和绑定触发使用同一计时计划。原始事件不改写，支持1×恢复、撤销重做、保存与配置往返；旧录制默认1×。
- 不识别加载、动画或技能冷却；移动时也可能在等待，遇到这类场景应保持1×，不宣称自动判断人的意图。
- 修复缓存目录短暂占用时的启动失败；在校验完成后等待占用释放，保持并发启动和使用中缓存的保护。
- 159项测试通过，独立EXE验证加速时长、试放设置、原始步骤保留及既有功能，14项缓存启动、复用、临时占用与修复检查通过。

## V2.0 正式版记录

2026-10-15，版本 `2.0.0`。窗口显示“轻云连点器 — V2.0”。

[下载 Windows 正式版](https://github.com/v-49/qingyun-clicker/releases/tag/v2.0.0)，文件名 `QingyunClicker-v2.0.exe`。GitHub 标记为正式版与 Latest。

- 保留原有动作组布局，每行独立设置间隔与持续时长，普通点按默认50 ms。
- 支持组合绑定、同键连发、改键、按住连发和组合持续按住。不同输出并行，共用输出按完整轮次协调。
- 全屏录制键鼠按下、松开、轨迹与滚轮；开始前原按钮直接显示3s → 2s → 1s，准备期间不录入。
- 游戏内F9或总启停键立即结束；最终Alt+Tab返回软件并结束时自动剪尾，保留中途切窗和游戏操作，原始录制可还原。
- 录制与普通动作同组运行，支持单次、循环、绑定触发、步骤编辑与插入、撤销和还原。
- 沿用原配置身份，保留已有动作组和总启停键。

138项测试及独立EXE、Windows原生事件与键鼠输出、13项缓存检查通过。完整测试记录与历史改动见[内测历史](v2-beta-release.md)。

正式包为Windows 10/11 x64便携EXE，无需安装Python；启动会请求管理员权限。软件生成的输入是否被具体游戏接受仍取决于游戏本身。
